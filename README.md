# LynnOS

![R2s build status](https://github.com/NuoFang6/LynnOS/actions/workflows/R2S-LynnOS.yml/badge.svg)  
本仓库用于编译**自用**的 openwrt 固件，仅支持 r2s（无风扇、仅RT5572无线网卡、sd储存）  
本人没有经验，欢迎提出建议
